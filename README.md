# MY Goods and Elevation

Website for MY Goods and Elevation (goods lifts, elevators, lifting equipment).

- `PROMPT.md` – the full prompt for generating/extending the site (prototype + later catalogue)
- `index.html`, `styles.css`, `script.js` – static prototype with light/dark theme

## Run
Open `index.html` in a browser, or `python3 -m http.server`.

## Add your proof of work
1. Put photos in `assets/images/`, videos in `assets/videos/`.
2. List them in the `WORK` array at the top of `script.js`.
3. Replace the phone/email in `index.html`.
